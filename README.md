# Flashcard Deck App

A full-stack flashcard application built to help users create, manage, and study decks of cards. The app provides a responsive and intuitive UI with full CRUD functionality on both decks and cards.

## Features

- 🎨 **Responsive UI**: Built with React, Flexbox, and Bootstrap for a seamless user experience across devices  
- 🔁 **Full CRUD API**: RESTful endpoints to create, read, update, and delete decks and individual flashcards  
- 🧠 **Data Models**: Deck and Card models designed to efficiently manage relationships and application state  
- ⚙️ **State Management**: React hooks used to handle UI and data flow across the application  

## Tech Stack

- **Frontend**: React, Bootstrap, Flexbox  
- **Backend**: Node.js, Express.js  
- **Version Control**: Git & GitHub
